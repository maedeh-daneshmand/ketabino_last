# وبسایت کتابفروشی و کتابخانه دیجیتال کتابینو (Ketabino)

پلتفرم مدرن، فاخر و کاربردی مطالعه و خرید کتاب‌های الکترونیکی و کلاسیک به زبان فارسی و با طراحی کاملاً RTL.

طراحی بصری این پروژه به صورت وفادارانه بر اساس نمونه‌های ارائه‌شده (**تم رنگی ارگانیک و وینتیج**، **تم کتابفروشی کلاسیک Paperwild**، **قفسه سه‌بعدی و موشن چیدمان کتاب‌ها** و **پنل کاربری و مدیریت پیشرفته با آیکون‌ها و نشان‌های سه‌بعدی شیشه‌ای**) پیاده‌سازی شده است.

---

## 🌟 ویژگی‌ها و امکانات پیاده‌سازی شده

### ۱. رابط کاربری، تم بصری و موشن‌ها (Design System)
- **تم رنگی اختصاصی**: سبز جنگلی عمیق (`#1E3F20`)، سبز مریم‌گلی (`#7C9082`)، طلایی خردلی (`#D4A359`)، خاکی/تراکوتا (`#C76D55`) و کاغذ کاهی کهن (`#FAF6F0`).
- **فونت فارسی وزیرمتن (Vazirmatn)** به همراه اعداد کاملاً فارسی در سراسر وبسایت.
- **موشن سه‌بعدی ورق زدن کتاب**: با کلیک روی هر کتاب، مودال دو صفحه‌ای کتاب سه‌بعدی با انیمیشن باز می‌شود و مشخصات، بریده متن و گزینه‌ها نمایش داده می‌شود.
- **قفسه کتاب سه‌بعدی با عطف‌های ایستاده (Bookshelf)**: طبق تصویر موشن کتاب‌ها، کتاب‌ها با عطف‌های چرمی/پارچه‌ای روی قفسه چوبی به ترتیب چیده شده و با تکان و زاویه طبیعی متمایل می‌شوند.
- **پشتیبانی کامل از حالت روز و شب (Dark & Light Mode)** با ذخیره انتخاب کاربر.
- **جلوه‌های شیشه‌ای (Glassmorphism)** با پس‌زمینه‌های نیمه‌شفاف بلور شده و بردرهای نرم.

### ۲. صفحات و بخش‌های اصلی وبسایت
1. **صفحه اصلی (`/`)**:
   - نوار اعلان بالای صفحه با کد تخفیف اختصاصی
   - نوبار هوشمند، منوی ریسپانسیو موبایل، جستجوی زنده، نشانگر تعداد سبد و علاقه‌مندی‌ها
   - بخش Hero چشم‌نواز با تایپوگرافی کلاسیک و نمایش کتاب سه‌بعدی هفته
   - دسته‌بندی‌های دایره‌ای وینتیج با آیکون‌های متناسب
   - قفسه سه‌بعدی تعاملی کتاب‌های تک‌نسخه‌ای و برندگان جوایز معتبر
   - ویترین کتاب‌های برگزیده، پرفروش و منتخب ویراستار
   - پرتره‌های قوسی نویسندگان نامدار ایران و جهان
   - بنر معرفی و مزایای اشتراک طلایی
   - بریده کتاب روز و نظرات خوانندگان کتابینو
   - فوتر چندستونه سبز جنگلی همراه با فرم عضویت خبرنامه
2. **کاوش کتاب‌ها (`/explore`)**:
   - فیلتر زنده بر اساس دسته‌بندی‌های موضوعی (داستان، روانشناسی، فلسفه، تاریخ و...)
   - فیلتر بر اساس زبان (فارسی / انگلیسی) و نمایش کتاب‌های تخفیف‌دار
   - مرتب‌سازی بر اساس جدیدترین، امتیاز، تخفیف، ارزان‌ترین و گران‌ترین
   - قابلیت تغییر نحوه نمایش (شبکه‌ای Grid یا لیستی List)
   - چیپ‌های حذف تک‌تک فیلترها و دکمه پاکسازی کلی
3. **جستجوی هوشمند (`/search`)**:
   - جستجوی بلادرنگ در عنوان کتاب، نام نویسنده، مترجم، ناشر، شابک، دسته‌بندی و متن توضیحات
   - چیپ‌های جستجوی پرطرفدار و پیشنهادات سریع
4. **صفحه جزئیات کتاب (`/books/[id]`)**:
   - نمایش جلد با افکت عطف و سایه سه‌بعدی
   - اطلاعات کامل شناسنامه (شابک، سال نشر، صفحات، ناشر، امتیاز و درصد تخفیف)
   - دکمه‌های افزودن به سبد، مطالعه نمونه و **خرید سریع آزمایشی**
   - تب‌های توضیحات، سرفصل‌ها، درباره نویسنده و **سیستم ثبت دیدگاه و امتیاز با ذخیره در LocalStorage**
   - پیشنهاد کتاب‌های مشابه همان دسته
5. **ریدر پیشرفته دیجیتال (`/reader/[id]`)**:
   - مطالعه کاملاً بدون حواس‌پرتی
   - تنظیمات ظاهر: ۴ تم رنگی (روشن، کاهی سپیا، تیره شب، زمردی)، ۴ سایز فونت، ۳ حالت فاصله خطوط
   - ورق زدن با اسلایدر و دکمه‌های صفحه قبل/بعد
   - نشانه‌گذاری صفحات (Bookmark)
   - **ذخیره خودکار پیشرفت مطالعه در LocalStorage**: هنگام بازگشت به کتاب، دقیقاً از همان صفحه قبلی ادامه می‌یابد!
6. **پیشخوان و پنل کاربری (`/dashboard`)**:
   - بر اساس تصاویر *پنل مدیریت* و *امکانات پنل و مدل خوش بودن*
   - کارت خوش‌آمدگویی با آواتار و تاریخ روز
   - ۴ کارت آماری: کتاب‌های من، زنجیره مطالعه (Streak) با آیکون آتش، نقل‌قول‌ها، قفسه‌ها
   - کتاب در حال مطالعه با نوار پیشرفت و دکمه ادامه
   - نمودار حلقوی هدف‌گذاری سالانه (تکمیل شده و باقی‌مانده)
   - نمودار ستونی ساعات مطالعه هفتگی (شنبه تا جمعه)
   - نمودار درصد ژانرهای مورد علاقه کاربر
   - دستاوردهای سه‌بعدی (3D Glass Orbs) با پیشرفت باز شدن مدال‌ها
   - مودال ویرایش نام، بیوگرافی و هدف سالانه
7. **کتابخانه شخصی (`/library`)**:
   - تفکیک کتاب‌ها (همه، در حال مطالعه، تمام‌شده)
   - نوار پیشرفت برای هر اثر و دکمه پرش مستقیم به ریدر
8. **فهرست نشان‌شده‌ها (`/favorites`)**:
   - کتاب‌های موردعلاقه کاربر با امکان افزودن به سبد یا حذف سریع
9. **سبد خرید و خرید آزمایشی (`/cart`)**:
   - لیست اقلام با کنترل تعداد و قیمت
   - سیستم کد تخفیف (کدهای `KETABINO` برای ۲۰٪ تخفیف و `WELCOME10` برای ۱۰٪)
   - **خرید آزمایشی (Demo Purchase)**: با کلیک، کتاب‌ها فوراً خریداری شده و مستقیماً به کتابخانه شخصی کاربر اضافه می‌شوند و سبد خرید خالی می‌گردد!
10. **صفحه عضویت و اشتراک (`/membership`)**:
    - معرفی ۳ پلن: پایه رایگان، طلایی ماهانه و الماس سالانه با مقایسه کامل امکانات
    - انتخاب آزمایشی پلن و فعال‌سازی فوری در حساب کاربری
11. **درباره کتابینو (`/about`)**:
    - داستان شکل‌گیری، ارزش‌ها، آکاردئون پرسش‌های متداول و اطلاعات تماس

## 🛠 تکنولوژی‌ها و ابزارها

- **Next.js 15 (App Router)**
- **React 19**
- **TypeScript**
- **Tailwind CSS**
- **Lucide React** (مجموعه آیکون‌های وکتور مدرن)
- **Framer Motion** (انیمیشن‌ها و حرکت‌های سه‌بعدی)
- **LocalStorage API** (مدیریت دائم وضعیت بدون نیاز به بک‌اند)
- **Vazirmatn Google Font**

## 💻 نحوه اجرا به صورت محلی (Localhost)

۱. وارد دایرکتوری پروژه شوید:
```bash
cd ketabino_last
```

۲. بسته‌ها و وابستگی‌ها قبلاً نصب شده‌اند؛ در صورت نیاز:
```bash
npm install
```

۳. اجرای سرور توسعه محلی:
```bash
npm run dev
```

سپس در مرورگر خود آدرس زیر را باز کنید:
```
http://localhost:3000
```

## 🧪 تست و بیلد پروژه

- **بررسی صحت تایپ‌ها (Typecheck):**
```bash
npm run typecheck
```
*(با موفقیت کامل و بدون کوچک‌ترین ارور یا خطا اجرا می‌شود)*

- **بیلد نسخه نهایی (Production Build):**
```bash
npm run build
```
*(تمام ۱۲ روت به صورت بهینه و کامپایل‌شده بیلد شده‌اند)*
